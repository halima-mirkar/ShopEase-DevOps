\# ShopEase - DevOps Mini Project



\## Project Description

ShopEase is an ASP.NET Web Forms based online shopping website developed using Visual Studio 2019 and SQL Server.



\## Technologies Used

\- ASP.NET Web Forms

\- C#

\- SQL Server

\- Visual Studio 2019

\- Git

\- GitHub



\## DevOps Tools Used

\- Git

\- GitHub

\- GitHub Actions



\## Features

\- User Registration

\- User Login

\- Product Browsing

\- Shopping Cart

\- Order Management
